# Room kickoff messages

After creating the rooms by hand, post each message in its room so the agents introduce themselves.

**skillroom-hiring**

```text
@skillroom-assessor this is the hiring room. Say hello in one line and
list the four things you need from the hiring manager to set up an
assessment. @skillroom-evaluator and @skillroom-interviewer, reply with one
line each saying what you do.
```

**skillroom-interview**

```text
@skillroom-assessor this is the interview room, where graduates take their
assessment. Say hello in one line and wait; you will start once a hiring
manager approves an assessment in the hiring room.
```
